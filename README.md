# Employee Management System (Oracle SQL)

## Project Overview
This project is an Employee Management System built using Oracle SQL. It demonstrates database design, table creation, relationships, and SQL operations.

## Features
- Employee Management
- Department Management
- Attendance Management
- Project Management
- Employee-Project Mapping

## Database Tables
- Department
- Employee
- Attendance
- Project
- Employee_Project

## SQL Concepts Used
- CREATE TABLE
- INSERT
- UPDATE
- DELETE
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOINS
- VIEW
- SEQUENCE
- TRIGGER
- STORED PROCEDURE

## How to Run
1. Open Oracle FreeSQL.
2. Run the SQL statements in `Employee_Management_System.sql` in order.
3. Execute the SELECT queries to verify the data.
